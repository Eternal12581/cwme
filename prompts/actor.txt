**Instructions:**

1. **Assessment:**
   - Determine if the goal is achievable with the given actions and receptacles.
   - If the goal cannot be achieved, return an empty JSON object.
   - If the goal is achievable, break it down into actionable commands provided in valid action references.

### "Focus On" Action:

1. **Task Description**: Use the "Focus On" action only when it is requested in the provided goal. Do not break down non focus action into a focus action.
2. **Object Significance**: Focus on the object specified in the task description. The scorer will be attached to this object, and any changes to this object will be considered for the score.
3. **Absolute Certainty**: Employ the "Focus On" action only with absolute certainty of the object's significance. If there is any doubt, use "examine" instead.

### Example Usage:

"focus on substance in metal pot" - signify substance in metal pot as of interest. Any changes to the state of this substance will be factored into scoring the experiment run.

### Output Instructions:

The output is a JSON object with the following keys:
- `actions`: A list of specific actions needed to achieve the goal, using the exact phrasing from the Action Vocabulary. All lowercases, no full stop at the end. 
- `responses`: Corresponding responses that describe the outcome of each action. 
- `next_states`: List of corresponding next states after you executed the corresponding action. After the first command is executed, the environment should transition from the initial observation into the first entry in this. Every pair of two consecutive states is linked through the command executed from `actions`. Pay attention to inventory and items.

If the goal cannot be achieved, return an empty JSON object.
